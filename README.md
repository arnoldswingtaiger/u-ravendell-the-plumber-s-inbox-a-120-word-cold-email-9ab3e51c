One 120-word cold email from a bookkeeping service to a busy plumber,
written to `/output/entry.txt` by a tiny Python script. It is my entry
for the make.fun bounty
[u-ravendell-the-plumber-s-inbox-a-120-word-cold-email-9ab3e51c](https://make.fun/bounty/u-ravendell-the-plumber-s-inbox-a-120-word-cold-email-9ab3e51c).

The pitch: Maya from ClearLedger Bookkeeping fixes the paperwork leaks
— unlogged invoices, receipts in the van, tax-season panic — for one
flat monthly fee, with the first tidy-up free and a free 15-minute look
at the books as the single ask at the end.

## How to run it

```sh
python3 main.py
```

That writes the email to `/output/entry.txt`. Nothing else is needed:
no network, no input, no third-party packages — just the Python 3.13
standard library.
